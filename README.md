Rxplain
A drug information landing page with live search. Type a brand or generic name and get the official FDA label sorted into Uses, Dosage, Warnings, Side effects, Interactions, Special groups, Storage and Overdose. Includes a glassmorphism design with light and dark mode, and optional AI plain-language summaries.
Live:
https://rxplain-freeedor.vercel.app
https://rxplain-plsygp.v2.appdeploy.ai/
Data sources (free, no API key)
openFDA drug label API for label text
NIH RxNorm API for spelling suggestions
Pollinations text API for the optional AI summary. It only rewrites the label text already on screen, and the original text always stays visible.
Run it
It is a single static file. Open index.html in a browser. No build step.
