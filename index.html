From a name to a label in three steps

RxNorm

Match the name

Misspelled it? The NIH RxNorm service suggests the closest drug names so you still find the right one.

openFDA

Fetch the label

The structured product label comes straight from the FDA's public drug label endpoint, with manufacturer and effective date.

Rxplain

Sort and simplify

Label sections become tabs. An optional AI summary rewrites only that tab's label text, and the original stays right below it.

What you can look up

Each result is built from the sections the manufacturer filed. If a label leaves one out, its tab is greyed out instead of guessed.

For information only
